# Gardendless 鸿蒙版 v0.16.27（GP-Next）

跟随上游 **0.16.27**（GP-Next **1.6.0**）。

## 上游更新要点

- 回退低帧计算；
- GitHub 关卡窗口新增评价功能（仅本地，不上传）。

## 本次修复

- **游戏内导出存档是空文件**：系统文件选择器对目标只授予「写」权限，而写回时用了「读写」打开，
  被系统拒绝、只留下选择器建的空文件。改为只写打开，并让失败有提示。
- **GitHub 关卡点「游玩」提示「关卡文件不存在」**：新版把关卡读写交给一组由宿主提供的方法，
  壳层之前没有实现，取到空值就被当成"没有这个文件"。已补齐读写，关卡可正常下载并游玩。
- **音乐包导入**：导入 ZIP / 文件夹同样依赖宿主提供的接口，已补齐（目录、ZIP、manifest 三种来源）。
- **窗口 / 全屏 / 焦点相关方法**补齐；未实现的方法以后会在应用内日志留一行记录，不再静默失效。
- 导出到用户选择的位置后，应用目录内**保留一份副本**（游戏稍后再读也能读到）。

## 实测（平板）

启动正常、页面无报错；GP-Next 面板显示 1.6.0；导出存档 159 KB 成功且副本保留；
GitHub 关卡下载后可游玩；`test-music-pack.zip` 导入成功。
