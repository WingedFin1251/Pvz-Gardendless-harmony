# Gardendless 鸿蒙版 v0.16.15（GP-Next）

跟随上游 **0.16.15**（GP-Next **1.5.7**），并修了一个会导致**启动黑屏**的问题。

## 上游更新要点

- 新增超级机枪史诗任务、遥远未来关卡的推荐 / 挑战卡组；
- 新增 **Github 关卡窗口**（关卡自动更新，也可上传）；
- 设置窗口新增**音乐包**功能；
- 修了若干旧问题：存档导出被截断、计时器不截至、切换舞台效果时音乐不切换。

## 本次修复

- **启动黑屏**：新版启动时会调 `electronAPI.window()`，而这个环境里 `electronAPI` 只补了音乐包相关的几个方法，
  缺 `window()` 就抛错、停在加载场景（画面全黑）。壳层给 `electronAPI` 补了一层兜底：没有的方法按空函数处理。
- **导出/导入数据看起来不生效**：导入是同步写入，而"从本机回填存档"是异步且会覆盖，回填晚一步就把导入值盖回去。
  现在回填会跳过本次导入的键，并在结束后复核一次。
- **更新提示框关不掉**：新版用 `<dialog>` 弹更新说明 / 音乐包 / Github 关卡窗口，盖在页面最上层；
  而触摸层会把除自家面板外的触摸都转成游戏点击 ⇒ 框里的关闭按钮点不动。
  现在只要页面里有模态框，触摸就整段交给网页，点一下就关。
- 存档路径迁移是桌面版的事（因为 `%APPDATA%`），鸿蒙侧不需要迁移，存档键名不变。

## 实测（平板）

标题画面正常、`FPS 65~71`、页面无报错、GL ≈ 613 MB；GP-Next 面板显示 1.5.7，「导入 ZIP / 导入文件夹」正常。
