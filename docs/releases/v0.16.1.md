# Gardendless 鸿蒙版 v0.16.1（GP-Next）

游戏内容同步上游 **PvZ2 Gardendless v0.16.1**；GP-Next 前端由 1.5.2 升到 **1.5.5**。

> **本版只发布 GP-Next 变体。** `lite` / `base` 目前还没有对应的 0.16.x 负载，继续停留在各自的上一个版本。

## 游戏内容更新（来自上游 v0.16.1）

- **后端进程大幅修整，含个别音频播放**（上游说明：如遇音频问题属正常现象）。
  体现在负载结构上：音频资源从 `assets/resources/native/*.mp3` 迁到独立的 **`audio/`** 目录（约 +214 MB），
  启动流程改为**先初始化音频（`game-audio.js`）再加载引擎**。
- **新增 GitHub 关卡窗口**：关卡数据放在 Web 侧 `indexedDB`（`pvzge-github-levels`），会时常自动更新，
  也可前往 GitHub 上传关卡。
- **新增超级机枪史诗任务**（社区制作）。

### 关于"迁移存档路径"的提示

上游桌面版这次把存档目录从 `%APPDATA%\win` 改成了 `pvz2_ge_electron`，并给出了手动迁移步骤。

⭐ **鸿蒙版不需要做这一步。** 存档在应用沙箱的 `localStorage` 里，键名与旧版**完全一致**
（`PvZ2_PlayerProperties` / `PvZ2_Settings` / `gp-next-settings` / `gp-next-locale`），
直接覆盖安装即可，原有存档会照常读回（实测：升级后玩家与进度都在）。

## 本仓库（壳层与打包）改动

- ⭐ **补齐云存档相关命令的语义**：0.16.1 在启动最前面会检查"云存档日志"（`cloud_journal_read`）——
  返回 `null` 表示"没有未完成的云操作"（放行），**而命令报错会被判成"云存档恢复未完成"并停止启动**。
  鸿蒙版没有云同步后端，因此按真实语义补齐：
  `cloud_journal_read → null`、`cloud_trusted_status → {"available":false}`、
  `cloud_startup_result` / `cloud_save_failed → null`（纯上报型）。
  其余云操作（例如主动发起云端保存）仍会**明确失败**，不伪装成功。
- 负载 `index.html` 补回 `oncontextmenu` 抑制（长按不弹系统菜单）。
- 版本号 `0.15.0 → 0.16.1`，`versionCode 1000008 → 1000009`。
