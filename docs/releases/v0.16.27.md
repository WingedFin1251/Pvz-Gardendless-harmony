# Gardendless 鸿蒙版 v0.16.27（GP-Next）

跟随上游 **0.16.27**（GP-Next **1.6.0**）。

## 上游更新要点

- 回退低帧计算；
- GitHub 关卡窗口新增评价功能（仅本地，不上传）。

## 本次修复

- **游戏内导出存档是空文件**：系统文件选择器对目标只授予「写」权限，写回时却按「读写」打开，
  被系统拒绝后只留下选择器建的空文件。已改为只写打开，并让失败有提示。
- **GitHub 关卡点「游玩」提示「关卡文件不存在」**：新版把关卡读写交给一组由宿主提供的方法，
  壳层未实现，取到空值就被当成"没有这个文件"。已补齐读写。
- **模组装上了却启用不了**：新版把模组包存储交给宿主，壳层返回的数据格式不对，加载时报「包已损坏」。
  已按新版格式实现。
- **音乐包导入**：导入 ZIP / 文件夹所依赖的宿主接口已补齐。
- **窗口 / 全屏 / 焦点相关方法**补齐；未实现的方法会在应用内日志留一行记录，不再静默失效。
- 导出到用户选择的位置后，应用目录内**保留一份副本**（游戏稍后再读也能读到）。
