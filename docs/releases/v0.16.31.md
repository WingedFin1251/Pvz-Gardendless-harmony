# Gardendless 鸿蒙版 v0.16.31（GP-Next）

跟随上游 **0.16.31**。

## 上游更新要点

- 优化豌豆射手系列动画；
- 回退低帧计算；
- **加入黄油生菜**（新植物）；
- GitHub 关卡窗口新增评价功能（仅本地，不上传）；
- 修复 GitHub 关卡窗口因服务器域名更替而不获取新关卡的问题。

## 本次修复

- **卸载文件夹式模组**：新版由宿主删除 `gp-next/packs/` 下的本地包源；壳层已补齐，且只允许删该目录内的内容。
- **扩展包（`gp-extension.` 前缀）**：新版要求宿主校验发布者签名，壳层尚未实现，因此会**明确提示失败**而不是静默跳过；普通模组不受影响。
- **面板「打开链接」「退出」**不再静默失效：外链交给系统浏览器，退出正常结束应用。
